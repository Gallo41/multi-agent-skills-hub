# Setor 03 — Frontend, UI, Design System & Mídia Visual

Este setor agrupa todas as skills e regras de direção de arte, interfaces web/dashboards, combate a UI genérica ("AI slop"), temas, arte generativa, recursos de design (MCP) e compatibilidade no Windows.

## Regras do Setor
- [`regras/matriz-decisao-visual.md`](./regras/matriz-decisao-visual.md) — Como escolher e combinar `frontend-design`, `gemini-frontend-design`, `design-taste-frontend`, `antiwebslop`, `pocket-design`, `theme-factory`, `canvas-design`, `algorithmic-art` e `web-artifacts-builder`.
- [`regras/compatibilidade-windows-ui.md`](./regras/compatibilidade-windows-ui.md) — Execução obrigatória via Git Bash + `pnpm` para `web-artifacts-builder` no Windows.
